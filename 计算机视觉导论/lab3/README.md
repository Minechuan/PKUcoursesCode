# Assignment 3

This release contains four problems:

- `MaskRCNN/`: the object detection / instance segmentation question reused from Assignment 4
- `depth_pc/`: back-project a depth map into a point cloud
- `mesh_pc/`: sample point clouds from a triangle mesh
- `mini_nerf/`: implement the rendering core of NeRF without training

## Notes

- This homework is mostly lightweight, but `MaskRCNN` requires PyTorch and a short CPU training run.
- For `MaskRCNN`, please complete `dataset.py`, then run `train.py` and `visualize.py`. The scripts save checkpoints and visualizations to `MaskRCNN/results/`.
- The `MaskRCNN` question uses a very small dataset of 10 samples and 3 training epochs to keep the runtime manageable on CPU.
- `MaskRCNN/train.py` starts from scratch when there is no checkpoint in `MaskRCNN/results/`, and resumes from the latest checkpoint if you rerun it.
- For `mini_nerf`, we provide an analytic radiance field in `scene.py`. You only need to implement ray generation, point sampling, and volume rendering.
- For `mini_nerf`, use pixel centers for ray generation and compute depth as the weighted sum of sampled `t` values.
- The release package should not include reference RGB or depth arrays for `mini_nerf`; grading should compare student outputs against a hidden reference on the instructor side.
- For `depth_pc`, the `depth.png` and `seg.png` files are generated by `render.py`, which uses `pyrender` to render `spot.obj` onto the 2D image plane.
- If your `depth_pc` implementation is correct, the reconstructed point cloud should overlap with `aligned_full_pc.txt`.
- For `mesh_pc`, we use the mean distance version of Chamfer Distance in this assignment.

## Suggested Environment

We recommend a Python environment with the following packages:

```bash
python -m pip install --upgrade pip
pip install numpy matplotlib opencv-python trimesh tqdm pillow imageio h5py tensorboard
```

For `MaskRCNN`, you also need PyTorch and Torchvision. For example:

```bash
pip install torch torchvision
```

Optional packages:

```bash
pip install pyrender
```

If you want to compute EMD for `mesh_pc`, you can use:

```bash
cd mesh_pc
git clone https://github.com/j2kun/earthmover.git
```

## Submission

- Use the provided `pack.py` to package this release directory into a submission zip. The script skips transient cache files such as `__pycache__/`, `.ipynb_checkpoints/`, `.pyc` files, and helper repos such as `mesh_pc/earthmover/`.
- Before running `pack.py`, replace the placeholder student `id` and `name` in the script so the generated zip file is named correctly.
- Submit the generated zip file to the course system.

```bash
results
```
